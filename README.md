# Generative AI Engineering 2026

### Artificial Intelligence | Python | LLMs | AI Agents | RAG

Repositório dedicado à minha jornada de aprendizagem em **Engenharia de Inteligência Artificial Generativa**, com exercícios, laboratórios e projetos práticos desenvolvidos durante a formação *Engenheiro de IA Generativa 2026: IA na Prática*, na Udemy.

## Objetivo

Desenvolver competências práticas na construção de aplicações inteligentes, integração de modelos de linguagem (LLMs), sistemas RAG, agentes de IA e automação de processos.

Este repositório documenta a evolução dos meus conhecimentos, desde os fundamentos de Python até à implementação de soluções avançadas de Inteligência Artificial.

## Tecnologias e ferramentas

- **Linguagem:** Python
- **Modelos e APIs:** OpenAI, Gemini, Groq, Hugging Face
- **Frameworks de IA:** LangChain, LangGraph, LlamaIndex
- **Agentes inteligentes:** CrewAI, Agno
- **Automação:** n8n
- **Dados:** SQL, PostgreSQL, SQLite, NumPy, Pandas
- **Interfaces:** Gradio
- **Ferramentas de desenvolvimento:** VS Code, Git, GitHub, Claude Code
